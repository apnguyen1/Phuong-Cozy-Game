# PCW-02 — Mobile and desktop interface design

**Status:** Planned; not started  
**Priority:** P1 — foundation  
**Suggested owner:** UI/UX (unassigned)  
**Dependencies:** 01  
**Owned scope:** Future interface specification and screen designs

## Purpose

Keep touch play comfortable without covering the room or friends.

## Deliverable

Exploration HUD, journal, tap-select/place panel, reading panel, gathering invitation; phone landscape and desktop compositions.

## Acceptance criteria

- Movement and jump regions stay clear.
- Free camera drag space remains.
- Every action has a touch route.
- Close/cancel and busy/saved/error states are specified.
- Buttons use text plus state cues.
- Desktop retains the same actions.

## Limits and open decisions

First pass is visual design only. Static images do not demonstrate working controls or accessibility.

## Validation

Review small phone and tablet layouts, keyboard navigation order and contrast before implementation.

## Execution boundary

Ticket creation is authorized. Implementation, scripting, Studio building and publishing are not started in this task. The user explicitly requested no code. Follow the [approved map](../design/map-proposal-v0.2.md) and [visual brief](../design/visual-direction-v0.1.md); measurements remain test targets.
