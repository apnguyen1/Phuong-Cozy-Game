## Suggested sequence

1. Review the palette and images (01), then settle the interface states (02) and shared contribution rules (13). Collect personal details (15) as available.
2. When implementation is separately requested, start world/camera space (03), then room (04), street (05) and Quad (06).
3. Implement the six activities (07–12) against shared behavior from 13. Room and outdoor activities can be developed independently once their interfaces are agreed.
4. Add the gathering (14), then rehearse across devices (16).

## Shared completion rule

Every future ticket must preserve mobile and desktop access, independent third-person cameras, real group participation, the one-bedroom interior, and the empty user-authored note. Changes to shared progress or scene connections must be reflected in dependent tickets. Do not add a room, economy, forced cinematic, or extra quest without a scope decision.
