# Garden decoration source policy

This folder intentionally contains no uploaded image, mesh, or external texture. `GrassDecoration.luau` creates native Roblox Parts and sphere meshes using the exact world palette.

Owned content:

- sparse grass clumps at measured lawn-safe sites;
- untextured outer-Quad tree silhouettes only;
- no replacement of `QuadPlanting`, existing interior trees, paths, benches, signs, planters, window boxes, or activity stations.

The existing community-tree texture exception does not apply to these new objects. Any future texture requires a separate user decision, source-raster mapping, and updated verification contract.
